# Does the deep-fryer opening replicate on fresh NM2 seeds

| Field | Value |
| --- | --- |
| Status | done |
| Area | build |
| Result | refuted |
| Created | L10.I1 |
| Updated | L10.I4 |

## Hypothesis

The deep-fryer playbook gets a chest by about 2:30, a first evolution and more damage by 2:00 than the old Steam Vent opening on seeds it has not met, as in the TIBO10 full run.

## Method

Fresh live games with the unchanged playbook on new seeds, 300 s. Record first chest listed and opened, chests by 2:30, first evolution time, damage at 2:00, elites killed and hp at 2:00.

## Findings

Deep-fryer died on all three fresh seeds (7171 2:08, 7272 1:15 and 1:20, 7373 1:21), losing 100-120 hp in minute 0-1 each time. The TIBO10 opening did not replicate. See B186.
