# Does a Frozen Fries start (freeze crowd control, Permafrost Fries with Thick Skin) beat deep-fryer on early damage, chests and minute-1 hp on live NM2

| Field | Value |
| --- | --- |
| Status | done |
| Area | build |
| Result | refuted |
| Created | L9.I7 |
| Updated | L9.I8 |

## Hypothesis

Frozen Fries freeze the pests that chip Tibo in minute 0-1, so hp at 2:00 and chest flow are higher than with deep-fryer on the same seeds.

## Method

5 live fresh NM2 games of 300s on seeds 6161, 6262, 6363, 6464 and 6565, paired against the plain deep-fryer games on the same seeds. Record damage by 2:00, elites, chests, minute-1 hp loss, hp at 2:00, first evolution and survival.

## Findings

Lived 2 of 5 (s6464, s6565) with damage by 2:00 not clearly above deep-fryer; the three deaths had 0 chests and hp 12-29 at 2:00. Deep-fryer stays the start. See B168.
